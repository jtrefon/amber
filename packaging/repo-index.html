amber-agent packages

Signed apt and dnf repositories for the amber AI agent harness.

Install

curl -fsSL https://jtrefon.github.io/amber-packages/install.sh | sudo sh

Ubuntu (including WSL2) and Fedora. The script verifies the signing key fingerprint before writing anything, adds the repository, and installs amber-agent. Read it first if you like: install.sh.

Verify the key yourself

gpg --show-keys --with-fingerprint \
  https://jtrefon.github.io/amber-packages/keys/amber-agent-archive-keyring.asc

Fingerprint: C373A7C2F4BB30ABEB1B35DAAAFCEAE6C29E0D1B

Update

Updates arrive with the normal system update (apt upgrade, dnf upgrade). amber-cli update runs the right one for the system it is on.

Repository layout

  • apt/dists/stable/InRelease — signed apt index
  • rpm/fedora/x86_64/repodata/repomd.xml — rpm metadata
  • keys/ — the archive signing key
