# Task: graph BFS distances

Implement `std::vector<int> bfs_distances(int n, const std::vector<std::pair<int,int>>& edges, int source)`
in `bfs.cpp` (declaration in `bfs.h`): nodes are 0..n-1; return the shortest
path length from `source` to every node, using -1 for unreachable nodes. Use
breadth-first search. Do not change the signature.
