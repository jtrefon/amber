# Amber Vision

**AI on Linux, unleashed.**

---

## The north star

Amber is a single, unstoppable agentic tool that replaces the fragmented
market of Claude Code, OpenCode, Codex, Aider, and every other agentic
harness. One tool. One interface. One mental model.

Linux is the armour: stability, longevity, tool integration, the entire UNIX
philosophy. AI is the brain. Together they form something no other platform
can match — a tool you can trust with a single fix or an entire project,
leave running for days, and come back to results.

## The spirit

God-like power wrapped in a terminal, delivered through an interface inspired
by BitchX and the golden age of IRC. Fast, keyboard-driven, dense, beautiful.
A tool that feels like home to anyone who lives in a terminal.

The drawer pops on `/`, filters as you type. Aliases like `/q` for quit and
`/sl` for session list become muscle memory. The status bar tells you what
you need at a glance — activity, tokens, jobs, clock.

The interface anticipates. It helps. It gets out of your way when you know
what you're doing.

## Who it is for

- **Developers** — from a single file to a monorepo
- **Sysadmins** — server management, automation, deployment
- **Researchers** — data analysis, experiments that run for days
- **Anyone** who SSHes into a box and wants an AI partner

## What it does

- Writes, edits, refactors, tests, reviews code
- Manages servers, runs commands, monitors systems
- Searches and understands codebases, docs, APIs
- Manages itself — sessions, config, providers, jobs
- Learns — remembers patterns, improves over days
- Persists — runs unattended for hours or days

## The user promise

- Your agent runs until it's done
- You drive it with commands, it talks back in the scrollback
- Every action has a command; every command has feedback
- Help is one `?` away at any depth — never retype the path

## What we stand for

| We are | We are not |
|--------|------------|
| Terminal-native | A web app |
| Keyboard-first | Mouse-driven |
| Local-first, self-hosted | SaaS or telemetry |
| Linux-powered | A Windows or macOS port |
| Composable with UNIX tools | A walled garden |
| Insert-always | A modal editor |
| Compiled, integrated | A plugin platform |

## The competition

The market is fragmented. Every tool does one thing — and none of them do it
on Linux properly, with a real TUI, background jobs, long-running support,
and the full power of the UNIX environment.

Amber replaces all of them because amber doesn't compete on features. Amber
competes on **integration**: the agent, the terminal, the tools, the files,
the sessions, the jobs — all in one shell, one set of commands, one muscle
memory.
