## Release gates

- `make test` under g++ and clang++; PTY suite; bench.
- ASan/UBSan and TSan jobs.
- `make check` and gate report; class-size/complexity/nesting/debt/hygiene/duplicates.
- `make lint` and `make analyze` on pinned CI tools; `format-check-changed`.
- `shortcut_collisions() == 0` for the documented core tree.
- No plugin root registration; plugin commands under `/plugin/<id>`.
- PTY coverage: shortcuts/drawer, Work board/viewer lifecycle, two-project sessions.
- No direct push to `main`; feature branches and squash-merge PRs per AGENTS.md.
- Version bump to 0.6.0 after all epics; Homebrew tap sync.
